## Learnings

- React renders components from the entry point in `src/index.js`.
- JSX lets components combine JavaScript expressions with HTML-like markup.
- A class component can keep local state and update it from an event handler with `setState`.
- The active example keeps the apple count in state and re-renders the heading after each click.
- Keeping examples separate from the active entry point makes it easier to study concepts without changing the running app.
